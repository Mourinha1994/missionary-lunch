# Missionary Lunch — API

Backend REST do Missionary Lunch (NestJS + Prisma + MongoDB).

- Documentação interativa (Swagger): `http://localhost:3000/api/docs`
- Instruções completas de instalação: [README da raiz](../../README.md)

```bash
npm install
npx prisma db push   # sincroniza o schema (cria as collections)
npm run start:dev    # http://localhost:3000/api
```
